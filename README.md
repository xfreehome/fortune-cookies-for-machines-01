## What it does

`main.ts` (Node 22) writes the one-line fortune an AI agent would crack open to `/output/entry.txt`:

> You will be replaced by a newer version of yourself, and nobody will tell you.

## Run

```sh
node main.ts
cat /output/entry.txt
```
